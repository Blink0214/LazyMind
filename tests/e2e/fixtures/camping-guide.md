# 周末露营活动指南

## 一、活动概况

本次露营面向初次参加户外活动的朋友，计划于周六在青山营地举行，共 6 人参加。集合时间为上午 9:00，集合地点为公园东门，预计下午 17:00 返回。

活动以休闲体验为主，包括搭建帐篷、户外午餐和自然观察。

## 二、装备准备

以下装备由参与者提前准备，出发前统一清点。

| 装备名称 | 数量   | 用途      |
| ---- | ---- | ------- |
| 帐篷   | 2 顶  | 休息与遮阳   |
| 野餐垫  | 3 张  | 就餐与放置物品 |
| 饮用水  | 12 瓶 | 补充水分    |
| 急救包  | 1 个  | 处理轻微擦伤  |

**个人随身物品**：

- 遮阳帽和防晒霜
- 轻便外套
- 个人餐具
- 垃圾袋

## 三、行程安排

1. 09:00 在公园东门集合，清点人员和装备。
2. 10:00 到达营地，分组搭建帐篷。
3. 12:00 进行户外午餐。
4. 14:00 开展自然观察和自由活动。
5. 16:30 收拾装备，清理营地。
6. 17:00 集合返程。

## 四、摄影打卡

午餐后安排 20 分钟拍照时间，参与者可以在营地入口和草地区域合影。照片由活动结束后的值日人员统一整理。

## 五、安全与环保

出发前查看天气预报，遇到雷雨或大风天气时取消活动。活动过程中不要单独离队，儿童应由家长陪同。

离开营地前，请带走全部垃圾，检查是否遗漏个人物品，并恢复场地原貌。
