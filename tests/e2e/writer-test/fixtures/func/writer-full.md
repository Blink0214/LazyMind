# 台风天安全防范指南

## 台风来临前的准备工作

台风来临前的准备工作是整个安全方案的基础环节。在这一阶段，应优先完成信息获取、环境隐患排查和应急物资储备，以便在台风登陆时能迅速采取避险措施。

首先，应密切关注气象部门发布的台风预警信息。可通过中央气象台、当地气象局官方渠道或手机应急预警应用，持续跟踪台风的实时路径、中心最大风力、移动速度以及预计登陆时间与影响范围。准确的气象情报是后续所有决策的前提，任何侥幸心理都可能埋下严重隐患。

排查居家环境隐患是第二项关键任务。您需要逐一检查所有门窗的锁扣与铰链是否牢固，必要时应加装防风板或使用胶带在玻璃上贴出“米”字形图案，以减少破碎时的飞溅风险。如果居住区域历史上曾出现过强风损坏，应优先用木板或专门的防风卷帘对窗户进行临时加固。

阳台、窗台和室外空调机架是容易被忽视的危险区。台风来临前，必须将阳台上的花盆、拖把、衣架、杂物以及任何可能被强风吹落的物品移入室内或用绳索牢固固定。同时，对空调室外机、太阳能热水器等外挂设备进行检查，确保其支架无锈蚀、螺栓无松动。这些看似微小的动作，能有效防止高空坠物对行人及周边建筑造成伤害。

应急物资的储备直接关系到台风期间家庭的基本生活保障。应提前准备足够全家人使用至少三天的饮用水和不易腐败的方便食品，如罐头、压缩饼干、即食食品等。此外，手电筒、备用电池、充满电的大容量充电宝、蜡烛及防水火柴也是不可或缺的应急物资。家庭急救箱内的常用药品、慢性病患者的处方药以及个人卫生物品同样需要提前准备，以应对可能出现的停水、停电和就医不便的情况。

最后，人员出行与避难规划在准备阶段就要落实。非必要情况下应果断取消所有户外活动与差旅计划，严格避免前往海边、山体、河道等危险地带。所有家庭成员都应在台风来临前知晓所在社区的应急避难场所的具体位置，并通过官方发布的安全转移路线图模拟一次疏散过程。对于家中有老人、儿童或行动不便者的情况，应提前向社区或物业管理单位报备，确保在紧急转移时能获得及时援助。

## 台风期间的安全措施

台风正式侵袭期间，一切行动应围绕“确保生命安全”这一核心目标展开，任何财产或好奇心的考量都必须为此让位。

一、严格留在室内，远离危险区域

台风登陆时，室外环境瞬息万变，阵风强度足以将人卷走，飞散的碎片可能造成致命伤害。因此，您和所有家庭成员必须严格留在结构坚固的室内，严禁外出。在选择停留位置时，应主动远离窗户、落地玻璃门、天窗以及其他可能因风压或飞溅物而破裂的易碎物品。如果窗户未加装防风板，建议拉上厚重窗帘，并选择无窗的内墙、走廊、洗手间或储藏室作为临时避难点。切勿出于观察心态靠近窗边，台风期间玻璃自爆或被异物击碎的情形并不罕见，碎裂的玻璃碎片往往会造成次生伤害。

二、积水区域的紧急断电与用电安全

在强降雨持续的过程中，如果所在房屋或办公场所发生雨水倒灌、室内进水，应立即采取断电措施。在有条件且确保自身安全的前提下，迅速切断该区域的总电源开关和分路空气开关，并将所有正在使用的电器拔掉插头。同时，必须避免接触任何带电设备——包括被水浸泡的插座、开关、电线和家电，防止因绝缘失效而引发触电。即使积水已经消退，受潮的线路和电器在未经过专业人员检测前也严禁尝试通电或触摸，否则可能引发放电事故或二次火灾。

三、严禁前往海边、河道、地下空间及低洼地区

台风期间，水域相关灾害往往是造成群死群伤的主因。必须在思想上划出绝对红线，做到不前往、不靠近、不逗留。具体而言：

- 海边与堤岸： 风暴潮与天文潮叠加可以引发数米高的增水，巨浪可瞬间将人卷入海中。无论风眼来临期间是否出现短暂的风雨减弱，都不可误认为危险已过而前往海边观浪或拍摄。
- 河道与行洪区： 上游来水可能在毫无征兆的情况下形成洪水，导致河道水位暴涨、流速激增。不要在桥面、河岸驻足观望水流。
- 地下通道、地下车库及下沉式建筑： 这些区域是城市内涝中风险最高的所在。暴雨可能使地下空间在短时间内被大量积水灌满，出入口被淹后逃生通道将完全阻断。如果台风来临时您恰好位于此类区域，应果断提前撤离至地面以上的安全高度，切勿心存侥幸。
- 低洼地带： 居住在地势低洼地段的居民，应提前向高处转移。如果身陷内涝，不可涉水行走，积水中不仅存在无盖窖井、锐利物体等看不见的危险，还可能因带电设备漏电而致死。如有必要且安全许可，可以借助长杆探路，但首选仍是等待专业救援。

## 台风过后的注意事项

台风过境后，天气的短暂好转往往容易让人误以为危险已经完全解除，实际上灾后环境中潜藏着诸多次生风险。这一阶段的核心原则是：在没有接到官方明确的风险解除通知前，仍须保持高度警惕，所有行动应以安全评估为前提。

一、等待权威风险解除通知

台风过后，切勿因风雨减弱而立即外出或返回危险区域。气象台发布的台风预警解除信号并不等同于所有风险均已消除，您应当持续关注政府应急管理部门、防汛抗旱指挥部以及社区发布的后续风险公告。以下几个要素必须得到确认后，才能逐步恢复正常活动：

- 台风预警信号已由当地气象部门正式解除，且后续无新一轮强降雨或大风预报。
- 所在区域的主要道路积水已基本消退，交通与公共设施经职能部门检修后开放。
- 社区或物业明确通知楼宇结构安全，无燃气泄漏、地基沉降等风险。
- 已经正式收到有关部门关于避险安置点可以安全返回的指令。

在等待期间，即使通过窗户看到户外逐渐恢复平静，也请继续保持居家状态，不要外出围观抢修现场、不要在损坏的建筑旁逗留，更不要擅自返回已被淹或存在坍塌风险的建筑物内取物。任何提前外出的行为，都可能因尚未被发现的隐患而引发伤亡。

二、外出时主动规避次生灾害

灾后外出往往是生活恢复的必要步骤，但必须严格做到“观察、判断、慢行”。台风扫过后的城市环境中，主要存在以下高致死致伤因素，您在出行时应当逐一识别并绕行：

- 倒伏树木与断裂枝干： 行道树在饱水土壤中根基松动，倾伏以及半折断的树木随时可能二次倒落。切勿从树底、电力线交织的树冠下方穿行，须主动绕开并提示同行人员远离。
- 损坏的广告牌与建筑附着物： 很多广告支架、门店招牌、空调外罩在风灾中已经发生结构性损伤，仅是暂时悬挂。应抬头观察沿街建筑外立面，有坠落风险的位置务必快速通过，不要在危墙、倾斜的围挡或脚手架旁停留。
- 积水区域： 即便洪峰已过，低洼地段仍可能存在深度不明的积水。积水中极有可能掩藏着无盖窖井、断落的电缆、尖锐的碎片或塌陷坑，绝不能贸然涉水。若必须通过积水路段，只可选择在有安全保障且已开放的人行路径上通行，同时避免触碰路灯杆、信号灯桩等金属设施，以防地下线路漏电传导。
- 断落电线： 这一点需要特别强调——台风过后，导线脱落是触电致死的最大隐患。发现断落或垂挂的电线时，必须将其一律视作带电线路进行应对。保持八米以上的安全距离，不自行清理、不接触周边水渍，并第一时间拨打供电服务热线或市政热线报告险情。同时，也要警惕倒伏电杆和倾斜的变压器，切勿靠近更不可试图翻越。

如果所在区域基础设施受损严重，建议非必要不出行，由社区或单位统一获取物资补给。若因抢救贵重物品或施救而必须出行，务必结伴行动并告知他人路线目标，全程携带手机保持通信畅通。

三、系统排查房屋与用电设备

回到家中不等于立刻恢复生活常态，在全面检查之前，房屋和内部环境仍可能是一片危险区。应按以下顺序系统排查：

1. 房屋宏观状态检查： 首先站在室外安全位置观察房屋整体状况，注意有无墙体开裂、基础沉降、屋顶翻卷、大面积渗漏等严重结构损伤。一旦发现裂缝在扩大或有异响，切勿入内，应立即向物业或房屋安全鉴定部门报告。
2. 燃气与水管路排查： 进入屋内后，如果闻到煤气味或听到气流声，应立即打开窗户通风，迅速关闭燃气总阀，禁用一切明火和电气开关，并第一时间联系燃气公司派专业人员处理。同时，检查水管有无破裂和暗漏，对受污染区域进行防水封堵和清洁。
3. 用电系统严密检测： 电气系统的恢复是灾后安全中最容易被忽视也最为致命的一环。如果房屋曾进水或存在渗漏，必须严格按以下步骤操作，严禁任何侥幸行为和自我判断：不通电原则： 在专业电工实施检测前，保持总开关处于断开状态，所有电器不插电，不尝试开灯或使用热水器等大功率设备。由专业人员排查： 必须联系持证电工或由物业派专业人员对进户线路、配电箱、插座、开关的绝缘性能做逐一检测。被水浸泡过的线路极易发生绝缘击穿，即使外观干燥，内部仍可能存有水分。受损电器处理： 曾经与水接触的空调、冰箱、洗衣机等家电，不论外观损坏程度如何，均需经过厂家或专业维修人员拆卸、烘干、绝缘检测后方可重新通电使用。简单的外部擦拭和自然晾干无法保证内部电气安全，贸然通电极有可能烧毁设备甚至引发火灾。确认安全后逐步恢复： 只有在得到专业人员开具的明确“可以通电”的结论后，您才能由总路到分路逐级合闸，并逐台通电测试电器设备，全过程中需有人在场观察开关和线路有无异常发热、跳闸或异味情况，一有异常立即断电并再次报修。
4. 环境清理与卫生防疫： 检查房屋的同时，应及时清除底层和阳台的积水、淤泥，清理过程中须佩戴手套、口罩和防水鞋。用含氯消毒剂对被淹过的地面、墙面、厨卫区域做彻底消毒，打开所有门窗进行通风换气，防止霉菌滋生。对因灾害死亡的鼠类和虫害，要使用工具收集并进行无害化处理，随即洗手消毒。

台风过后的恢复过程切忌操之过急，正确的节奏是“先安全评估，再清理修复，最后恢复居住”。每一次看似繁琐的检查与等待，都是在为生命负责。只有经过层层确认，彻底排除隐患，您和您的家人才可以安心的回到正常的生活秩序之中。
