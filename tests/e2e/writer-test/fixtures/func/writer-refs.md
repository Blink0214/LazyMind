# 台风天安全防范指南

<a id="block-sec-001"></a>

## 1 台风来临前的准备工作

台风来临前，请务必关注官方预警信息，加固门窗，收好阳台物品，并储备至少三天的饮用水和食品。具体物资清单可参考[第2节](#block-sec-002)中的提示。

<a id="block-sec-002"></a>

## 2 台风期间的安全措施

台风登陆时非必要不外出，务必远离门窗、玻璃幕墙、低洼积水和广告牌。若必须外出，请先阅读[第3节](#block-sec-003)中的恢复指引。

<a id="block-sec-003"></a>

## 3 台风过境后的注意事项

待官方解除警报后再外出，避开倒伏树木和垂落电线，检查家中用电与燃气安全，并关注家人心理状态。
