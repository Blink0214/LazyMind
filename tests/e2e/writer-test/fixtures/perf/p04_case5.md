# 一、产品简介

## 1. 产品定位与核心功能

智享家 SmartHub X7 智能中控屏（以下简称"中控屏"）是一款专为家庭全屋智能控制而设计的中央交互终端。它以一块高清触摸屏为核心载体，将照明、空调、窗帘、安防、影音等各类智能设备的控制与管理汇聚到一个统一的入口，让您不再需要在多个手机 App 之间反复切换。

中控屏的核心功能可以概括为以下五个方面：

1. **全屋设备集中管控。** 通过一台设备即可查看并控制家中所有已接入的智能设备，状态一目了然，操作一步到位。
2. **场景一键联动。** 将多个设备动作打包成"场景"，例如一键"观影模式"可同时关灯、拉窗帘、打开投影仪，无需逐个操作。
3. **语音交互。** 内置远场麦克风阵列与语音助手，支持免唤醒词自然语音指令，即使双手占用也能轻松控制全屋。
4. **远程操控。** 配合"智享家"手机 App，出门在外也能随时查看家中状态、远程开关设备。
5. **安防监控。** 支持接入智能门锁、摄像头、烟感/水浸传感器等安防设备，异常事件实时推送报警。

## 2. 适用场景与兼容设备

中控屏适用于客厅、卧室、玄关、书房等各类家居空间，尤其适合已部署或计划部署多品类智能设备的全屋智能用户。无论您是正在装修新房，还是对现有住房进行智能化改造，中控屏都能为您提供简洁高效的控制中枢。

在兼容设备方面，中控屏支持以下主流协议与品类：

| 协议类型 | 典型设备品类 |
|---|---|
| Wi-Fi | 智能灯泡、智能插座、扫地机器人、空气净化器 |
| Zigbee 3.0 | 门窗传感器、人体传感器、温湿度计、智能开关 |
| 蓝牙 Mesh（BLE） | 智能灯带、小夜灯、温控阀 |
| Matter | 跨品牌兼容设备（需固件支持） |

> 提示：具体的兼容设备型号列表会随固件更新不断扩充，请定期关注"智享家"App 内的设备市场，获取最新的支持清单。

## 3. 产品外观与部件说明

中控屏采用简约的方正造型，正面为一块 7 英寸 IPS 高清触摸屏，屏幕分辨率 1024×600，支持五点触控。整机以白色磨砂质感外壳包裹，适合搭配各种家居风格。下面对各部件进行逐一说明。

**正面部件：**

- **触摸屏：** 主要的显示与交互区域，所有操作均通过触摸完成。
- **状态指示灯：** 位于屏幕右上方，蓝色常亮表示正常运行，红色闪烁表示配网中或故障，熄灭表示休眠。
- **近场麦克风：** 屏幕上边框设有近场麦克风开孔，用于精确语音拾音。
- **光感传感器：** 位于屏幕左上方，用于自动检测环境亮度并调节屏幕背光。

**侧面与背面部件：**

- **电源按键：** 位于机身右侧，短按唤醒/熄灭屏幕，长按 10 秒可强制重启。
- **音量按键：** 位于机身右侧电源键下方，可上下调节提示音与媒体音量。
- **扬声器：** 位于机身背面，用于语音回复、提示音与音乐播放。
- **壁挂支架接口：** 背面设有标准 VESA 壁挂孔位，配合附赠支架可固定于墙面。
- **电源接口：** 位于机身底部，为 Type-C 接口，连接电源适配器供电。

# 三、安装连接

## 1. 安装方式：壁挂与桌面

中控屏提供壁挂与桌面两种安装方式，您可以根据家居空间与使用习惯自由选择。

### 1.1 壁挂安装

壁挂安装适合将中控屏固定在玄关、客厅墙面等固定位置，作为家庭智能控制的常驻入口。步骤如下：

1. 选择平整、坚固的墙面（承重墙或实心砖墙为佳），避开空心墙板与水管/电线暗管区域。
2. 将壁挂支架贴于墙面，用铅笔标记四个螺丝孔位。
3. 在标记处打孔，敲入膨胀螺丝套。
4. 用螺丝将壁挂支架固定在墙面上。
5. 将中控屏背面对准支架卡扣，向下挂入并轻压，确认卡紧。
6. 将电源线沿墙面理线槽引入底部接口，接通电源。

### 1.2 桌面安装

桌面安装适合将中控屏放置在茶几、床头柜或书桌等平面上，方便随时拿起查看。步骤如下：

1. 将附赠的桌面支架底部保护膜撕除。
2. 将中控屏底部卡槽对准支架凸起，向下按入直至听到"咔哒"声。
3. 将支架放置于稳固平整的台面上，确保底座充分接触台面。
4. 连接电源线并接通电源。

> 注意：桌面安装时请确保放置位置稳固，远离桌沿及儿童易触达区域，以防设备跌落损坏。

## 2. 电源接通与首次开机

完成物理安装后，即可通电开机：

1. 将 Type-C 电源线一端插入中控屏底部电源接口。
2. 将电源适配器连接市电插座。请确保使用原装适配器，使用非原装适配器可能导致设备损坏或安全隐患。
3. 通电后，屏幕将自动亮起并显示开机引导动画，首次开机约需 30-60 秒。
4. 开机完成后，系统将自动进入"欢迎使用"配置向导。

> 注意：首次开机时请勿中途断电，以免系统初始化异常导致无法正常启动。

## 3. Wi-Fi 配网与账号绑定

首次开机后的配置向导将引导您完成 Wi-Fi 配网与账号绑定，这是实现远程控制和场景联动的必要前提。请按以下步骤操作：

1. **选择语言与时区：** 在欢迎页面选择您使用的语言（简体中文/English）及所在时区。
2. **连接 Wi-Fi：** 在网络设置页面，选择家中 2.4GHz Wi-Fi 网络，输入密码并确认。中控屏目前仅支持 2.4GHz Wi-Fi，暂不支持 5GHz 频段。
3. **下载 App：** 用手机扫描屏幕上的二维码，下载并安装"智享家"App（支持 iOS 与 Android）。
4. **扫码绑定：** 打开 App 注册/登录账号后，使用 App 内的"扫码绑定"功能扫描中控屏上显示的二维码，完成设备与账号的关联。
5. **设置房间：** 根据实际户型在 App 中创建房间（如客厅、主卧、厨房），并将中控屏分配到对应房间。

> 提示：配网过程中请确保手机与中控屏连接至同一 Wi-Fi 网络。如果配网失败，请检查 Wi-Fi 密码是否正确、路由器是否开启了 AP 隔离，并尝试将设备靠近路由器后重试。

# 四、功能操作

## 1. 主界面模块与交互

开机并完成配置后，中控屏将显示主界面。主界面以卡片式布局呈现，自上而下依次排列以下模块：

- **顶部状态栏：** 显示当前时间、天气信息、Wi-Fi 信号强度与消息通知角标。
- **常用设备区：** 横向排列您设置为"常用"的设备快捷卡片，单击即可快速开关。
- **场景快捷区：** 横向排列已创建的场景按钮，如"回家""离家""观影"等，单击即可一键执行。
- **房间切换栏：** 底部设有房间标签，左右滑动可在不同房间之间切换，查看各房间内的设备。
- **功能入口栏：** 最底部提供"全部设备""场景""安防""设置"等图标入口。

交互方面，中控屏支持单击、双击、长按三种手势。单击进入设备控制详情页，双击可快速切换设备分组，长按设备卡片可进入编辑模式以调整位置或删除设备。

## 2. 设备添加、分组与场景设置

### 2.1 添加设备

要将新的智能设备纳入中控屏管理，请按以下步骤操作：

1. 确保新设备已通电并处于配网/待绑定状态（通常长按设备上的配网键 5 秒，指示灯快闪即进入配网模式）。
2. 在中控屏主界面点击"全部设备"，选择右上角"+"按钮。
3. 系统将自动搜索附近可绑定的设备，从列表中选择目标设备并确认。
4. 为设备命名（如"客厅主灯"），并将其分配到对应房间。
5. 等待绑定完成，设备卡片将出现在对应房间的设备列表中。

> 注意：部分 Zigbee 设备需要先在中控屏中添加 Zigbee 网关功能（中控屏内置 Zigbee 协调器，可直接作为网关使用），添加时请按设备说明书要求进行入网操作。

### 2.2 设备分组

当同一房间内同类设备较多时（如客厅有多个射灯），可将它们编入一个分组进行统一控制：

1. 进入"设置 → 设备分组"，点击"新建分组"。
2. 输入分组名称（如"客厅射灯组"），选择所属房间。
3. 从设备列表中勾选需要纳入分组的设备，确认保存。
4. 分组创建后，将在设备列表中以分组卡片形式展示，点击可同时控制组内所有设备。

### 2.3 场景设置

场景功能允许您将多个设备动作打包，实现一键联动。创建场景的步骤如下：

1. 在主界面点击"场景"，进入场景管理页面，点击"+"新建场景。
2. 输入场景名称并选择一个场景图标。
3. 点击"添加动作"，依次选择设备并设定目标状态（如：客厅主灯 → 关闭，窗帘 → 关闭，投影仪 → 打开）。
4. 可选：设置场景触发条件（如手动触发、定时触发、传感器触发）。
5. 保存场景，场景快捷按钮将自动出现在主界面的场景快捷区。

> 提示：您可以创建最多 50 个自定义场景。常用的场景建议拖动排列在场景快捷区靠前位置，方便日常快速调用。

## 3. 语音控制与远程操控

### 3.1 语音控制

中控屏内置智能语音助手，支持免唤醒词自然语音交互。您只需面向屏幕说话，即可控制全屋设备。以下是一些典型的语音指令示例：

- "把客厅的灯打开。"
- "空调调到 26 度。"
- "打开观影模式。"
- "现在卧室温度多少？"

> 注意：语音唤醒的有效距离约为 3-5 米，建议在安静环境下使用。环境噪音过大或距离过远可能影响识别准确率。为保护隐私，语音数据仅在设备本地处理，不上传云端。

### 3.2 远程操控

配合"智享家"App，您可以在任何有网络的地方远程操控家中的设备：

1. 打开手机上的"智享家"App，使用已绑定的账号登录。
2. App 主界面将同步显示中控屏的全部设备与场景，操作方式与中控屏一致。
3. 点击任意设备卡片即可远程控制，点击场景按钮可远程执行场景。
4. 在"消息"页面可查看设备状态变化、安防报警等通知记录。

> 提示：远程操控需要中控屏保持联网状态。如果家中网络中断，远程控制将暂时不可用，但中控屏本地的设备控制与已配置的本地联动（如 Zigbee 设备间的联动）仍可正常运行。

# 五、场景联动

## 1. 联动规则的概念与创建

场景联动是中控屏的核心进阶功能。与手动一键执行的场景不同，联动规则是"自动触发"的：当满足特定条件时，系统会自动执行预设的动作，无需人工干预。例如"日落时自动拉上窗帘""温度高于 28 度自动开空调"等。

一条联动规则由三个要素组成：

- **触发条件：** 定义"什么时候触发"，可以是时间、设备状态变化或传感器事件。
- **执行条件（可选）：** 在触发条件满足时，额外判断是否满足某些限制（如仅在特定时间段内生效）。
- **执行动作：** 触发后执行的操作，可以是控制设备、运行场景或发送通知。

创建联动规则的步骤如下：

1. 进入"场景 → 联动规则"，点击"+"新建规则。
2. 设置触发条件，选择触发类型（定时/设备状态/传感器事件），并配置具体参数。
3. 可选：添加执行条件，限定规则的生效时段或前提。
4. 添加一个或多个执行动作。
5. 为规则命名并保存，规则将立即生效。

## 2. 典型场景示例

为了帮助您快速理解联动规则的用法，以下列举几个实用的典型场景。

### 2.1 回家模式

- **触发条件：** 智能门锁被指纹解锁（识别为家庭成员）。
- **执行动作：** 玄关灯亮起、客厅主灯开启、空调调至 26 度、窗帘打开、音响播放欢迎音乐。
- **效果：** 推开家门的那一刻，温馨舒适的环境已经准备就绪。

### 2.2 离家模式

- **触发条件：** 中控屏"离家"按钮被点击，或最后一个家庭成员的手机离开 Wi-Fi 网络。
- **执行动作：** 全屋灯光关闭、空调关闭、窗帘关闭、扫地机器人启动、安防布防。
- **效果：** 安心离家，节能与安防一步到位。

### 2.3 睡眠模式

- **触发条件：** 每天定时 23:00，或卧室"睡眠"场景按钮被点击。
- **执行动作：** 全屋灯光渐暗关闭（除小夜灯外）、空调切换为睡眠温度曲线、窗帘关闭、安防夜间布防。
- **效果：** 营造舒适的睡眠环境，同时确保夜间安全。

## 3. 定时任务与条件触发配置

### 3.1 定时任务

定时任务是最简单的联动形式，按设定时间自动执行。配置方法：

1. 在联动规则创建页面，选择触发条件为"定时"。
2. 选择触发频率（仅一次/每天/每周指定星期/每月指定日期）。
3. 设定具体的触发时间。
4. 添加执行动作并保存。

例如，您可以设置"每天 07:00 自动打开卧室窗帘并播放新闻广播"，让清晨更加从容。

### 3.2 条件触发

条件触发基于设备或传感器的实时状态变化，实现更智能的自动化。常见条件类型包括：

- **设备状态变化：** 如门窗传感器检测到门窗打开、人体传感器检测到有人移动。
- **环境数值变化：** 如温湿度传感器检测到温度高于设定阈值、PM2.5 传感器检测到空气污染加重。
- **多条件组合：** 可设置多个条件的逻辑组合（"全部满足"或"任意满足"）。

> 提示：配置条件触发时，建议设置合理的"防抖"参数（即两次触发之间的最小间隔时间），避免传感器抖动导致的频繁误触发。例如人体传感器建议设置至少 5 分钟的触发间隔。

# 六、故障排除与售后保修

## 1. 常见故障排查

在使用过程中，如果您遇到以下常见问题，请先尝试对照排查表自行解决。以下故障排查表覆盖了用户反馈频率最高的几类问题。

| 故障现象 | 可能原因 | 排查与解决方法 |
|---|---|---|
| 屏幕不亮、无法开机 | 电源未接通或适配器故障 | 检查电源线两端是否插紧；尝试更换插座；长按电源键 10 秒强制重启 |
| 无法连接 Wi-Fi | 密码错误/频段不对/距离过远 | 确认密码正确；确认使用 2.4GHz 网络；将设备靠近路由器重试 |
| 设备搜索不到/无法绑定 | 设备未进入配网模式/Zigbee 未就绪 | 长按设备配网键重新进入配网模式；检查中控屏 Zigbee 功能是否开启 |
| 语音无响应 | 麦咪被遮挡/距离过远/环境嘈杂 | 确认麦克风未被遮挡；在 3 米内清晰说话；移至安静环境重试 |
| 触摸不灵敏 | 屏幕有污渍/贴膜影响 | 用柔软干布清洁屏幕；如有贴膜建议移除后测试 |
| 设备状态显示离线 | 设备断电或网络中断 | 检查设备是否通电；检查家中网络是否正常；重启中控屏 |
| 场景或联动未触发 | 条件配置有误或被禁用 | 进入规则详情检查触发条件与执行动作；确认规则处于"启用"状态 |

> 提示：若以上方法均无法解决问题，请记录故障现象并联系售后服务，我们的技术人员将为您提供进一步协助。

## 2. 恢复出厂设置与固件升级

### 2.1 恢复出厂设置

当设备出现严重异常、或您准备将设备转让他人时，可以执行恢复出厂设置。该操作将清除所有个性化配置、已绑定设备与联动规则，恢复为出厂状态，请谨慎操作。

**方法一（菜单操作）：** 进入"设置 → 系统 → 恢复出厂设置"，输入管理员密码后确认。

**方法二（按键操作）：** 在关机状态下，长按电源键与音量减键同时保持 15 秒，屏幕出现恢复提示后按指引确认。

> 注意：恢复出厂设置前，建议通过"智享家"App 的"数据备份"功能导出您的场景与联动配置，以便日后恢复。

### 2.2 固件升级

我们会定期推送固件更新，以优化性能、修复问题并增加新功能。固件升级可通过以下方式完成：

1. **自动升级：** 进入"设置 → 系统 → 固件升级"，开启"自动升级"。系统将在检测到新版本后，于凌晨 3:00-5:00 静默自动更新。
2. **手动升级：** 在同一页面点击"检查更新"，如有新版本可点击"立即升级"。升级过程中设备将自动重启，请勿断电。

> 注意：升级过程中切勿拔掉电源或强制关机，否则可能导致系统损坏。建议在电量充足且网络稳定的情况下进行升级。

### 3.1 保修政策

本产品自购买之日起享受如下保修服务：

- **整机保修：** 24 个月，涵盖非人为损坏的硬件故障。
- **电源适配器保修：** 12 个月。
- **不在保修范围的情况：** 人为摔落/进水导致的损坏、自行拆机或使用非原装配件造成的故障、自然灾害等不可抗力因素造成的损坏。

保修期内，符合保修条件的故障维修免费（含工时费与配件费）。超出保修期或属于不在保修范围的情况，我们将提供有偿维修服务。
