# F5 计划与待验收事项

更新：2026-10-23。以当前实现（提交 `47393a9ad`）为基线。本文只记录当前范围和剩余工作；实现见 [F5-IMPLEMENT.md](F5-IMPLEMENT.md)，字段见 [WRITING-UPSTREAM-AGREEMENTS.md](WRITING-UPSTREAM-AGREEMENTS.md)。

## 已落实的范围

- `writing/` 内独立提供 `write_outline`、`write_document`、`revise_document`，复用公共 Writer，不再合并到单一 draft 入口。
- 大纲独立展示和编辑，确认后继续正文；正文要求已有大纲，只输出稿件，不重建或覆盖确认大纲。
- 支持 JSON 业务附件及 Markdown、SVG/PNG/JPG 输入，常用文件在写作节点内解析，不新增 paper_files slot。
- 图表归属缺失时补齐规划，保留既有章节结构及图片归属；正文使用现有图片和文献，不重新生成实验结论。
- 直接修订按本轮要求；按审稿修订默认使用当前全部结构化意见，不提供部分意见选择功能，不使用 revision_options slot。
- 稿件与审稿版本匹配只证明适用性，不代表用户意图；保留是否采用审稿的模型判断。
- 修订只输出稿件，不同步大纲、不强制全文字数；新稿仍执行字数和一致性检查。
- 大纲、正文和修订接入既有流式事件及失败预览撤回机制。

## 下一轮真实前端验收

必须上传原附件、使用实际模型和前端，不能用 mock 结果代替。附件索引见 [examples/README.md](examples/README.md)。最新简化尚未重新完成真实前端链路验收。

| 场景 | 需要确认的结果 |
| --- | --- |
| Markdown 材料＋SVG，未提供大纲 | 生成独立大纲，流式及进度可见，编辑保存后明确确认，再继续正文 |
| 已有大纲，图片归属缺失/部分缺失 | 不改变标题结构及已有归属，补齐剩余图片；正文各图正确显示 |
| 大纲确认后写作 | 使用确认的大纲版本；正文保存后大纲内容与材料版本不被重建或覆盖 |
| 直接修订，存在历史审稿 | 只按本轮要求修改，历史审稿不自动参与；不受旧全文字数目标阻挡 |
| 按当前完整审稿修订 | 无需选 ID；可执行文字意见得到处理，补材料/实验意见不被伪装完成 |
| 空审稿、无可执行修改、过期审稿 | 明确停止或提示，不强制生成改动，不使用过期意见 |
| 保存、重新打开及失败场景 | 全文与图片正确恢复；失败预览撤回，已保存稿件不被覆盖 |

## 范围约束

不新增意见勾选 UI、修订参数 slot、修订后自动再审稿节点或通用框架；不扩大到 F1–F4 内部改造。当前 `revise_document` 只接 finish；如需修改路由，另行确定需求。

程序仍保留内部意见 ID 和范围检查，用于关联修改计划，不能因取消用户选择而删除。对明确要求只处理部分意见的请求先澄清，不静默扩大为全部。
